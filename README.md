# Customer Shopping Analysis

An end-to-end data analytics project analyzing customer shopping behavior using **Python, SQL, and Power BI**.

The project focuses on understanding purchasing patterns, customer behavior, product categories, payment methods, subscription behavior, discounts, and customer spending differences.

---

## Project Overview

This project analyzes a customer shopping dataset to identify meaningful patterns in customer purchases and translate them into business insights.

The analysis follows an end-to-end workflow:

**Data Cleaning → Exploratory Data Analysis → SQL Analysis → Power BI Dashboard → Business Insights**

---

## Objectives

- Understand customer purchasing behavior
- Analyze average purchase amounts across categories
- Compare spending behavior across age groups
- Analyze payment methods and purchase amounts
- Compare subscribers and non-subscribers
- Analyze the impact of discounts on purchase amounts
- Identify highly rated products
- Identify frequently purchased products within categories
- Segment customers based on previous purchase behavior
- Build an interactive dashboard for business reporting
